# Ithaca City

A 768 x 768 circular, layered, walled capital that runs on the same data pack as the RIFTBREK headquarters (same doors, kits, sorters, lockdown). Generated by `tools/riftbrek/build_ithaca.py`; schematic `dist/RIFTBREK_ITHACA_CITY.litematic`.

World placement (default): **origin X 12288, Z 8192** (local 0,0), Y -64..319. Region files: `r.24.16 r.24.17 r.25.16 r.25.17` (no entity files). The HQ base sits at X 8192..10111, so the two never share a region file. Change it with `config/riftbrek.properties` (`cityX`, `cityZ`) or `/rift city <x> <z>` (this only tells the mod where the files are).

## Layout (r = distance from the centre)
- r < 24: central monument (92-block obelisk, amethyst crystal, fountain plaza)
- r < 150: **Royal District**: Royal Palace (north, throne hall, 4 corner towers, 80-block spire), Capitol (south, columned portico, glass dome, lockdown control room), inner fortress wall r150..156 with 4 leader-tier gates
- r 162..212: **central marketplace** ring (market stalls with chests, 4 trading halls with villager workstations)
- r 222..300: six Vanguard faction HQs (Birds, Unstables, Abstracters, Veil, Archivist, Wildcards), Grand Library & Archives, military barracks + 2 training arenas, industrial redstone district, transit hub, harbour, ~210 residential townhouses, gardens
- river across the south + harbour basin with quays, piers, 3 ships, customs house, lighthouse; the river passes the outer wall through iron-bar water gates
- r 322..334: outer curtain wall (66 blocks high, walkway, battlements), 4 main gatehouses (outer public checkpoint + inner member checkpoint), 20 wall towers, 4 beacon watchtowers on the ring road
- underground: maintenance ring tunnel + 4 radial tunnels (4 member-gated hatches), minecart loop (half-size 190) with 4 stations, royal vault, 2 sorter halls, Veil secret tunnels

## Systems that exist
| system | how |
|---|---|
| Faction-restricted doors, lockdown | 35 command-block gates calling the existing `riftbrek:door/<tier>` functions (public / member / leader / royal / one per faction). Lockdown closes everything but royal gates. |
| Identity verification | the data pack's ID books and `/trigger rb_req` commands; signs at each gate say how |
| Kits | kit pads at the HQ entrances (existing `kit/pad_*` functions) |
| Sorting + storage | two sorter halls (same functions as the HQ), fed by a **hopper shaft** from an intake chest beside the farms; service ladders from each hall to the industrial hall |
| Item transport | the hopper shaft above; minecart loop for people |
| Minecart network | powered-rail loop with 4 stations and ladder exits to the avenues |
| Farms | 4 crop plots (wheat, carrots, potatoes, beetroot) with water and a chest each. **Manual**: you harvest and replant; there is no automatic harvester |
| Lighting controls | street lamps on the avenues switch on after dark via inverted daylight sensors |
| **Redstone Haven** | ground floor of the industrial district: logic-gate lab, hopper clock, chest-fill meters, piston curtain, all real redstone; **self-tested on a live server** (`docs/REDSTONE_HAVEN.md`) |
| Wind-charged chicken launcher | real redstone, see `docs/LAUNCHER.md` (tested: a rider in the open cell is thrown ~3.5 blocks) |
| Hidden passages | Veil tier bookshelf-framed gate, a Veil tunnel out through the wall (iron trapdoor exit) |
| Secure vault | royal vault under the throne hall behind a royal-tier gate, 27 loot chests |
| Maintenance access | ring tunnel + radial tunnels, member-gated hatches |

## Not built (be aware)
- **Flying-machine transport**: not built.
- **Automatic farms** (iron/mob/crop harvesters): not built; the farms above are manual.
- **Villagers** are not placed (schematics from this generator carry no entities): the trading halls have the workstations, you bring villagers.
- **Equipment distribution** = the existing faction kit pads only.
- Sorter intake is the one hopper shaft; the markets/barracks are not connected to it.
- Interiors are procedurally furnished (partitions, chests, beds, lecterns, bookshelves), not hand-designed.

## Tested
- Static: 0 block-state problems against Minecraft 1.21.11 data, 0 world/support errors, all 35 gates resolve to real data-pack functions, **37 of 37 key places reachable on foot** (doors counted open), exported region files read back identical (2,304 chunks).
- Real Fabric 1.21.11 server: loads with 0 errors, `/rift verify city` gives 9 / 9 PASS, the chicken launcher fires and launches a mob. Door logic uses the same functions that passed the 7-case door test in the HQ.
- NOT tested with a real player: doors in the city, kit pads, minecarts, the sorter halls end to end, lockdown, the Veil tunnels.
